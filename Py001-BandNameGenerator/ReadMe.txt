# Band Name Generator
A beginner-friendly Python project that generates a band name using your birthplace and pet's name.

## Features
- Takes user input
- Generates a personalized band name

## Requirements
- Python 3.x

## Usage
```bash
python main.py
```

## Example
```text
Welcome to Band Name Generator!
Enter your birthplace name:
Delhi
Enter your pet's name:
Rocky
Your band name should be Delhi Rocky
```
